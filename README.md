## About

When Dungeons Arise generates enormous, handcrafted structures across your world — mushroom villages, undead pirate ships, floating castles, thornborn towers and shogun mansions. Each is a multi-level build with hidden rooms, layered loot and a real sense that someone designed it.

---

## Features

- Twenty-plus large handcrafted structures across many biomes
- Multi-floor interiors with hidden rooms, traps and layered loot
- Biome-appropriate placement — pirate ships at sea, castles in mountains
- Balanced loot tables that reward exploration without breaking progression
- Configurable spawn rarity per structure type

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **When Dungeons Arise** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Where do structures spawn?**
A: Across most biomes, at configurable rarity — a structure locator makes finding them practical.

**Q: Is the loot overpowered?**
A: It is tuned for mid-game exploration; loot tables are configurable per structure.

**Q: Existing world?**
A: Structures only generate in new chunks — travel outward.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
